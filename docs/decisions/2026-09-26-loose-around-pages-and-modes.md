# Decision: The organisation map stays loose around pages and modes

- **Status:** decided 2026-09-26
- **Source:** `docs/organisation/README.md`, find "Loose around pages and modes (owner decision, 2026-09-26)."

Organisation areas describe the job code does, never a page or a mode, and every page sits in App experience whatever mode it serves. Adding, moving, renaming or retiring a page or a mode therefore needs no map edit.

If this summary and the source ever differ, the source wins.
