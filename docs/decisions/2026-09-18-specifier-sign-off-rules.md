# Decision: How specifier definitions are signed off

- **Status:** decided 2026-09-18
- **Source:** `docs/specifier-definition-worklist-2026-09-18.md`, find "Owner instruction, 2026-09-18: proceed on the recommendations."

The specifier sign-off value is `clinician-reviewed-approved`, only one named clinician (today the owner) may set it, and each specifier gets one definition with a per-disorder note only where it genuinely differs. Severity and remission for sexual dysfunctions and paraphilic disorders are out of scope.

If this summary and the source ever differ, the source wins.
