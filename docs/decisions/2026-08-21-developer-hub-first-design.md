# Decision: The developer hub is read-only, snapshot-based and for deciding what next

- **Status:** decided 2026-08-21
- **Source:** `docs/superpowers/specs/2026-08-21-developer-hub-phase-1-design.md`, find "Decisions taken (owner, 2026-08-21)"

The developer hub is a read-only page built from a build-time snapshot with an honest age stamp, meant for deciding what to do next rather than for browsing. It is designed desktop-first but still held to the phone-chrome gate.

If this summary and the source ever differ, the source wins.
