# Decision: Mode identity colours get their own token family

- **Status:** decided 2026-09-13
- **Source:** `docs/design-system/TOKENS.md`, find "Mode identity — the owner decision, 2026-09-13"

A mode's identity colour comes from its own family of four tokens, including a contrast partner, kept separate from the category tones. Every mode uses the product accent until it declares a hue, and On Call was the first to do so.

If this summary and the source ever differ, the source wins.
