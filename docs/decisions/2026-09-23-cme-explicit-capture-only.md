# Decision: CME activities are captured explicitly, never automatically

- **Status:** decided 2026-09-23
- **Source:** `docs/cme/design/cme-design-decisions.md`, find "Owner decision, 23 September 2026: explicit capture only."

A CME activity is recorded only when the doctor fills in and saves the form. Opening a document never creates an activity or starts a timer, and there is no passive reading history or automatic attendance.

If this summary and the source ever differ, the source wins.
