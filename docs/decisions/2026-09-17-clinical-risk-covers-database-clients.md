# Decision: Database client and On Call privacy code count as clinical-risk

- **Status:** decided 2026-09-17
- **Source:** `scripts/pr-policy.mjs`, find "Owner ruling 2026-09-17, after a clinical-governance review of the list above"

Changes to the database client code (which holds the service-role key) and to the On Call repository (which hides personal entries from other users) are classed as clinical-risk, so they are flagged for clinical governance review. The same ruling covered the Caring Contacts code.

If this summary and the source ever differ, the source wins.
