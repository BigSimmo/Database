# Decision: On Call section headers show the page's groups and no back arrow

- **Status:** decided 2026-09-13
- **Source:** `docs/on-call/design/mockup-conformance.md`, find "Owner instruction, 2026-09-13. The pocket card keeps its arrow"

On On Call section pages the second header row lists only the current page's groups, and there is no back arrow, because the mode pill is the way out. The page's name sits in the mode pill rather than in that row, and the sheet that More opens has a return control back to the page.

If this summary and the source ever differ, the source wins.
