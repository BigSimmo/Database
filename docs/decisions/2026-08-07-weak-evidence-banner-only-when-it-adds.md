# Decision: The weak-evidence banner shows only when it adds something

- **Status:** decided 2026-08-07 (the source gives no date; this is when it was first recorded)
- **Source:** `docs/design-system/HANDOVER-2026-08-07.md`, find "the two kinds that say something the notice cannot"

The retrieval banner on an answer appears only for stale evidence and partial retrieval, the two cases where it says something the verification notice cannot; elsewhere the notice alone carries the caution.

If this summary and the source ever differ, the source wins.
