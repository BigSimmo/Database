# Decision: Tables on a cited page fold into the source drawer

- **Status:** decided 2026-08-24
- **Source:** `docs/answer-page-redesign-handover.md`, find "The table aside — GOES. Tables fold into the drawer."

The wide-screen table column beside the answer is removed, and a table on a cited page becomes a chip inside that source's drawer. The accepted cost is that a table can no longer be read side by side with the answer on a large screen.

If this summary and the source ever differ, the source wins.
