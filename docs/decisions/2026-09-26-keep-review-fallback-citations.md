# Decision: An abstaining answer's review fallback keeps its citations

- **Status:** decided 2026-09-26
- **Source:** `docs/outstanding-issues-inbox/460ada28-7c3f-4bdc-8303-fe6e45ede1d0.json`, find "keep current behaviour; the pinned divergence stays by design"

When an answer abstains but its review fallback still cites in-scope evidence, the behaviour stays as it is (#C2D9JF). Stripping those citations would also strip the useful pointer from genuine review stubs.

If this summary and the source ever differ, the source wins.
