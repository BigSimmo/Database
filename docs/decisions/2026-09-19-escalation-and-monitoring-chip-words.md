# Decision: The safety chips recognise escalation and monitoring word families

- **Status:** decided 2026-09-19
- **Source:** `docs/outstanding-issues.md`, find "Fixed 2026-09-19 in PR #2905, owner-approved for both words."

The safety chips match the word families "escalate" (escalates, escalated, escalating, escalation) and "monitor" (monitors, monitored, monitoring), with explicit endings so a word such as "escalator" does not match (#9XRDF7).

If this summary and the source ever differ, the source wins.
