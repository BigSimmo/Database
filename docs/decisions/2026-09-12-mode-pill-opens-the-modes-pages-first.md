# Decision: A mode's pill opens that mode's own pages first

- **Status:** decided 2026-09-12
- **Source:** `docs/on-call/design/on-call-hub-build-prompt.md`, find "The mode pill opens this mode's own pages first"

For a mode with its own pages and no results surface, the mode pill opens that mode's pages first, drawn like the mode switcher, with a way back to the full mode list. It is keyed on that property, not on a mode's name.

If this summary and the source ever differ, the source wins.
