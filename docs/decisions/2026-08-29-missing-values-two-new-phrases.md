# Decision: Two phrases were added for values that are missing only for now

- **Status:** decided 2026-08-29
- **Source:** `docs/design-system/SPEC.md`, find "(owner decision, 29 Aug 2026)"

"Not yet calculated" and "Withheld until complete" join the four missing-value phrases, because both situations occur and forcing them into the older phrases would assert something false. A bare dash is still never used.

If this summary and the source ever differ, the source wins.
