# Decision: Each medication's default source is its TGA Product Information

- **Status:** decided 2026-09-25
- **Source:** `docs/outstanding-issues.md`, find "OWNER DECISION: default source per medication is the TGA Product Information"

Each medication record's default source is its TGA Product Information, plus WA guidelines where they exist (#05WXHX). Engineering proposes the links, the owner confirms them, and high-risk medicines go first.

If this summary and the source ever differ, the source wins.
