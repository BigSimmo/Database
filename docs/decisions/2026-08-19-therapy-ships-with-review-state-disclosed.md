# Decision: Therapy is available with its review state disclosed

- **Status:** decided 2026-08-19
- **Source:** `docs/codebase-index.md`, find "The owner's decision (2026-08-19) replaced the gate with disclosure"

Therapy is available in production with its review state shown on every record, instead of being hidden until clinician sign-off. Per-record sign-off is still tracked and shown, but it no longer decides whether a record can be reached.
