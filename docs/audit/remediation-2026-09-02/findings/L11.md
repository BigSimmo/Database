`isCommittedGenerationMetadata` returns true whenever `committedGeneration` is null, so a document whose `metadata.index_generation_id` is absent shows rows from ANY generation; `committedGenerationFilter` likewise returns null (no SQL filter). The SQL predicate used by `search_document_chunks` evaluates `row_generation = NULL` → NULL → excluded, hiding the same staged rows.
