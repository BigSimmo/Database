**L111 · Safety-note text is cut at a fixed 257 characters, which can split a numeric token** — `src/lib/clinical-safety.ts:71-72` · quality/simplification · CONFIRMED · safe_cleanup=false · L02-F7

conciseSourceText() returns `normalized.slice(0, 257).trim() + '...'` with no word/number boundary, so a dose or count straddling index 257 is rendered partially. **Impact:** Chip shows e.g. 'ANC 15...' for 'ANC 1500'; the ellipsis signals truncation but the partial number is visible in a Safety finding. **Fix:** Cut at the last whitespace before 257 (and never inside `\d`), or at sentence end. **Skeptic:** The quoted lines cut at a fixed character offset with no word/number boundary, so a numeric token straddling index 257 is rendered partially before the ellipsis.
