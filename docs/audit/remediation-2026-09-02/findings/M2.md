### M2 · Privacy Impact Assessment data inventory omits the browser-side answer-thread and recent-query persistence of raw clinical query text

`docs/privacy-impact-assessment.md:78 (data inventory table) vs src/lib/answer-thread-storage.ts:3-8,195-238` · privacy/clinical · **CONFIRMED** · safe_cleanup=false · lane L02 (L02-F3)

- **Defect:** answer-thread-storage.ts writes the raw query text, the full generated answer and the source excerpts for up to 12 turns (≤4.5 MB, 12-hour TTL, key `clinical-kb-answer-thread:<ownerId>` including the `guest-tab-session` owner) to window.sessionStorage; recent-query-storage.ts stores the last 5 raw queries per owner. The PIA's only browser-storage statement is that Safety-Plan content stays 'in the current browser tab … no API request or browser-storage write' (lines 29, 78, 144) and the inventory table has no row for answer-thread/recent-query storage. grep of docs/privacy*.md and docs/clinical-governance.md for 'sessionStorage' returns nothing.
- **Trigger:** Any answer completed in the dashboard; the thread is restorable for 12 h on the same tab. Anonymous (public) users are persisted under the shared `guest-tab-session` key.
- **Impact:** The governance document the owner relies on for APP/PHI reasoning understates where incidental PHI (a typed patient scenario plus the derived answer) rests. Mitigations exist in code (sessionStorage dies with the tab, TTL, owner-scoped keys, clear-on-sign-out) but are undocumented, so a future change (e.g. localStorage) would not be caught as a PIA deviation.
- **Proof:** src/lib/answer-thread-storage.ts:6-8 (`answerThreadTtlMs = 12h`, comment 'bound how long raw query/answer text stays restorable'), :219-226 `window.sessionStorage.setItem(scopedStorageKey(ownerId), serialized)`; recent-query-storage.ts:27 setItem of raw queries. docs/privacy-impact-assessment.md grep for 'sessionStorage|session storage|answer thread' — no hits (traced, not executed beyond grep).
- **Fix sketch:** Add an inventory row: 'Answer thread + recent queries — browser sessionStorage (owner-scoped key, 12 h TTL, ≤12 turns, cleared on sign-out); contains raw query text, answer, source excerpts' and note the shared-workstation control; cross-reference tests that pin the TTL/clear behaviour.
- **Skeptic (CONFIRMED):** The PIA's data inventory does not record that ordinary-search raw query text, the generated answer and source excerpts persist in browser sessionStorage for up to 12 h (owner-scoped, TTL-bounded, size-capped), nor the last-5 recent queries. Line 513 covers Clinical Ask only, so it does not neutralise the omission. This is documentation drift, but it concerns privacy of incidental PHI and the PIA is the governance document of record, so Medium stands per the re-grade rule. Fix is doc-only and breaks nothing.
