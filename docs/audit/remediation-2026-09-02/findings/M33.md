- **Defect:** The register is described as 'the current machine-checked status authority' (docs/clinical-hazard-analysis.md:5) and each hazard lists `controlSymbols` plus `tests` as proof. The validator only (a) regex-matches each symbol somewhere in the controlPaths source and (b) checks each test path exists and matches `tests/*.test.ts`. It never checks that any listed test references the control symbol or the control path, so a test file can be emptied of the relevant case, or the symbol can be renamed and re-added as a comment, and the gate stays green. Today the manifest already links proofs that do not name the control: `deriveTrust` (H2, H5) appears in none of tests/source-governance.test.ts, answer-render-policy.test.ts, rag-score.test.ts, rag-retrieval-row-contract.test.ts; `collectSourceCandidates` (H4) in none of its three tests; `neutralizeIdentityField` (H6) not in tests/rag-injection.test.ts; H3 lists tests/ward-output.test.ts, which has zero references to `formatAnswerRenderCopyText` (the behaviour is in fact pinned indirectly via deriveAnswerRenderPolicy / buildRagSourceBlock, but the gate cannot tell). The gate is also outside `verify:cheap` and `.github/workflows/ci.yml` (only `governance:release`, which is provider-backed), so a 2026-11-23 `reviewExpiresAt` lapse or a control-symbol rename produces no PR signal.
- **Trigger:** Any PR that renames/removes one of the 13 control symbols or deletes the relevant `it(...)` case; or the calendar reaching 2026-11-23 (manifest.reviewExpiresAt) — none of these fail a PR check.
- **Impact:** The clinician-facing hazard register (H1–H6 'partial' with named proofs) can silently stop being true while `CLINICAL_HAZARD_CONTROLS_PASS` keeps printing; the ISO-14971-style status authority overstates what is machine-checked.
- **Proof:** not executed — traced. scripts/check-clinical-hazard-controls.mjs:157-163: `for (const symbol of hazard.controlSymbols) if (!new RegExp(\b${symbol}\b).test(controlSource)) errors.push(...)` where controlSource = concatenated controlPaths only; tests are validated at :140-146 by existsSync + `/^tests\/.+\.test\.(?:ts|tsx)$/` only. grep counts (command above) show 0 hits for deriveTrust / collectSourceCandidates / neutralizeIdentityField / formatAnswerRenderCopyText in the tests the manifest cites for them. package.json:182 is the only script invoking it; ci.yml has no match.
- **Fix sketch:** In validateClinicalHazardControls, for each hazard require that at least one listed test imports (or references) at least one controlPath module or controlSymbol (regex over the test source), and add `check:clinical-hazard-controls` to verify:cheap:internal / the CI static-pr docs scope (it is offline, ~1 s, needs fetch-depth 0 which CI already uses at ci.yml:95,214,454,519). Add a unit case to tests/clinical-hazard-controls.test.ts for a test file that names no control.
