Patient search

Finds a person by name, or a movement by its identifier, department, ward or owner. It never assesses risk, acuity or treatment, and it never ranks a person by need. A movement that has left the system, closed or arrived, is not here, and the page says so rather than leaving you to wonder.

What this page will not do

3 kinds

No risk or acuity score This screen holds none, so there is none to return and none to sort on. Search by name, identifier, department, ward or owner.

No best match A superlative asserts a comparison that did not happen. The order key is named above the results instead, so a reader can see what decided it.

No closed or arrived movement The list is filtered to open movements first and unconditionally, so a closed one cannot reach a row and be described as open. A ward that declined is still searchable, and matching a ward is never a destination.

What is real

  • The emergency departments, hospital sites, wards and health services, which are the repository's own WA names.
  • The seven movement stages and their labels, and that arrived and closed movements never appear.
  • That a destination reads only a ward that has accepted, never one that was merely asked.

What is invented

  • Every person, movement, department pairing, ward decision, wait and clock on this screen.
  • Every name, built from an uncommon given name and a word for a plant, a bird or a stone so that none matches a real person.
  • No record number is shown. This prototype invents none, so a movement is found by its identifier rather than by a patient record number.
