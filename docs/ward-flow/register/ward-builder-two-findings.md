## Read this column first — it is the point of the document

Column **STATUS** says how a finding was established. The three values are not degrees of
confidence; they are different kinds of thing.

| Value        | What it means                                                                             |
| ------------ | ----------------------------------------------------------------------------------------- |
| **TESTED**   | A check was RUN that would have FAILED if the claim were false. The strongest thing here. |
| **OBSERVED** | Somebody looked at the running screen, or at the real output, and saw it.                 |
| **REASONED** | Somebody read the code and worked it out. Nothing was executed.                           |

**A REASONED finding is not a weak finding — it is an unverified one.** Some of the most serious
things in this list are reasoned. But several reasoned findings of mine have turned out to be
**right in substance and wrong in mechanism**, and the mechanism is the half that changes what
somebody does about it.

**My totals: 9 TESTED, 15 OBSERVED, 18 REASONED in Part 1, and 24 REASONED in Part 2.**
Nothing has been rounded up.

⚠️ **A boundary on every green in this file.** These runs were made on this branch, whose test
runner config, type-check config and lockfile all differ from `origin/main`. **A pass here is a
pass under this branch's setup — it is not a prediction about what the shared build will say.**
