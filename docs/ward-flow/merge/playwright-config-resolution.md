### What this means for THIS merge

⚠️ **Both sides' at-risk tokens happen to be covered.** Ours are `ui-ward-*` (disk-enumerated);
main's are production specs (pr-shards). **So if you resolve this hunk wrongly, a test WILL go red
and name the file.** That is a genuine safety net for tonight — and it is luck about which tokens
these are, not a property of the guard. Do not generalise it to the next merge that touches this line.
