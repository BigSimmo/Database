Prototype

This page is not a medical device. Every team listed here comes from one extracted source document, no team has agreed to be represented here, and nothing on this page has been checked against a real service.

That source document contains near-duplicate and misspelled team names, and they appear here as they reach this page. Nothing on this page merges, corrects or de-duplicates them — two entries that read alike may be two real teams, one team recorded twice, or a typing error, and this prototype cannot tell which. Where names read alike the page marks them, so you can check you have the right one. Some spellings the document holds were already collapsed together before this page saw them, which the foot of the page sets out.

What on this page is invented

  • Nothing about any team. The 65 names are exactly the teams a referral in this prototype can name, in exactly the spellings it can name them — near-duplicates and misspellings and all.
    ⚠️ But this page is not showing you the source document, and an earlier draft of this line claimed it was. The catchment table holds 71 distinct spellings of a clinic name, and six pairs collapse into one the moment case and punctuation are normalised upstream, before this page sees anything — Wheat Belt with Wheat belt, Great Southern with Great Southern., Central Great Southern and Upper Great Southern each with a full-stopped twin, Mead Centre (Armadale) with Mead centre (Armadale), and East Wheatbelt HS with East.Wheatbelt HS. 71 less those six is the 65 shown here. So spellings the document really contains are already gone before the “reads alike” check runs, and it can only compare what reaches it.
    ⚠️ An earlier version of this very paragraph said 77 and seven, called it measured, and was wrong — not by arithmetic but by unit. It counted distinct values of the clinic column, which is not the same population as distinct clinic names: one of those values is empty, and five name two clinics joined by a slash (Peel/Rockingham, Kwinana/Peel, and three more). Six impostors, and 77 becomes 71. A wrong figure presented as measured is worse than no figure, because it survives the one check a careful reader makes. Whenever two counts have disagreed on this project the cause has been this and not arithmetic: each side measuring a different thing, and each right about the thing it measured.
  • The “reads alike” grouping is computed here, on this page, from the names alone. It is a spelling comparison, not a statement that two entries are the same service — and it will miss pairs written differently enough, so an unmarked name is not a guarantee of uniqueness.
  • “Recently opened” is your own browsing on this device. It is not held in any record and is not shared.
  • No caseload figures appear here at all. This is a way in, not a caseload — a team’s own page answers those questions for that team.
  • Teams are listed alphabetically because the record holds a team’s name and nothing else to group by. The catchment table this list is derived from does link each team to a set of suburbs, but that link is not carried on the team itself, so a regional grouping here would be one this prototype invented rather than one a team’s own record supports.
