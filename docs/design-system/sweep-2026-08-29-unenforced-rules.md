# Unenforced-rule sweep — 29 August 2026

**Scope.** The rules in this document set whose enforcement status is _absent, manual, partial,
advisory or deferred_, checked against the actual source. The enforced set
(`check:design-system-contract`, `check:type-scale`, `check:icon-scale`, `brand:check`,
`check:assets`, and lint's token/hex/icon/z-index rules) was **not** re-audited — it was reported
green before this sweep began and nothing here contradicts that.

**Method.** Read `GATES.md` in full, extracted every row labelled `manual`, `planned`,
`implemented-partial`, `advisory`, "known blind spot" or "still not enforced"; then read `SPEC.md`
§§9–11 and §4.13, and `COMPONENTS.md` §9 in full. Each candidate rule was checked against
`src/**` (mockups excluded, per `AGENTS.md`). Where a gate's own scope was load-bearing to a
finding, the gate implementation was read to confirm the blind spot mechanically rather than
inferred from the prose.

**Read-only.** No source file was modified. This report is the only file written.

**Honest summary.** Eleven findings, two of them substantial. The largest is a hard ban in
`TOKENS.md` §2 that 20 production controls violate and that the tap-floor gate cannot see by
construction. Twelve rules were checked and found clean; four `COMPONENTS.md` §9 "open defect"
rows describe defects the code has already fixed — the document is the stale party there.
