# Search header redesign

Runnable at `/mockups/search-header-redesign`.

Four directions for the shared search-results header chrome (Forms and every other
search mode). Each section shows desktop and phone in the same frame.

| #   | Direction      | Idea                                                                |
| --- | -------------- | ------------------------------------------------------------------- |
| 01  | Ledger strip   | Typography-first strip; no nested card; underline sort              |
| 02  | Command mast   | Dense instrument bar; graphite density; one control height          |
| 03  | Unified chrome | Mode + query + count share one header owner; Search chip removed    |
| 04  | Focus frame    | Single accent edge; phone refine disclosure; calm desktop utilities |

Design scratch only — not production chrome. Shared mockup shell chrome is suppressed
so the framed concepts are the only header on the page.
